# Contributing

Contributions are welcome. Please:

1. Report issues at [issues](https://github.com/yang227/data-warehouse-modeling/issues)
2. If adding skills, follow the superpowers-zh conventions (SKILL.md + references/ + scripts/)
3. Keep a practical tone — no textbook summaries, real experience preferred
4. Bilingual (Chinese + English) is preferred but not required
